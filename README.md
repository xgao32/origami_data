# `origami_data`

This repository contains dynamic light scattering (DLS) instrument exports, analysis code and notebooks, acquisition-level result tables, and plots. The `.exp` files are instrument exports; the CSV and PNG outputs are analysis.

The inventory below covers project files and generated Python bytecode. Repository internals under `.git/` are omitted.

## `DLS/`

- `20261103_3HAE-annealed_plot_data.csv` — Acquisition-level estimates and quality flags for the 3HAE annealed experiment, exported by an earlier DLS walkthrough from the instrument data and analysis helpers.
- `analyze_dls.py` — Command-line analysis script that reads Dynamics `.exp` files, fits acquisition curves, estimates PDI and hydrodynamic diameter, and generates plots and a summary CSV.
- `dls_walkthrough.py` — Reusable parser, cumulants-fitting, size-estimation, plotting, and summary functions imported by the walkthrough notebook.
- `__pycache__/dls_walkthrough.cpython-312.pyc` — Python 3.12 bytecode cache created automatically when `dls_walkthrough.py` is imported.

### `DLS/analysis/`

- `DLS_analysis_20261105_unannealed_3HAE_5HTB.ipynb` — Saved interactive analysis of the 5 November unannealed 3HAE/5HTB instrument export, with code and rendered results generated by notebook execution.
- `DLS_analysis_20261106_3HAE_5HTB_unannealed_reacquired.ipynb` — Saved interactive analysis of the 6 November reacquired unannealed 3HAE/5HTB measurements, with code and rendered results generated by notebook execution.
- `DLS_analysis_20261106_annealed_5HTB.ipynb` — Saved interactive analysis of the 6 November annealed 5HTB measurements, with code and rendered results generated by notebook execution.
- `DLS_analysis_20261109_nucleasefreewater.ipynb` — Analysis of the 9 November nuclease-free-water DLS export, with each plot saved under its dataset-specific folder in `DLS/plots/`.
- `DLS_analysis_2026111_empty.ipynb` — Analysis of the empty-sample DLS export, with each plot saved under its dataset-specific folder in `DLS/plots/`.
- `DLS_analysis_3HAE_walkthrough.ipynb` — Example, step-by-step analysis of the 3 November annealed 3HAE export; its tables and plots are produced by executing the notebook with `dls_walkthrough.py`.
- `DLS_analysis_AJH_v4_comparison.ipynb` — Comparison analysis for the 3HAE/5HTB DLS measurements, with plots saved in `DLS/plots/AJH_v4_comparison/`.

### `DLS/data/`

- `20261103_3HAE-annealed (2).exp` — Raw Dynamics export for the 3 November annealed measurement replicate, generated by the DLS instrument software.
- `20261103_3HAE-annealed.exp` — Raw Dynamics export for the 3 November annealed 3HAE and second measurement block, generated by the DLS instrument software.
- `20261103_3HAE-annealed_notsure5htb.exp` — Raw Dynamics export for the 3 November annealed measurement with an uncertain sample label, generated by the DLS instrument software.
- `20261105_unannealed_3HAE_5HTB.exp` — Raw Dynamics export for the 5 November unannealed 3HAE/5HTB measurements, generated by the DLS instrument software.
- `20261105_unannealed_3HAE_5HTB_plot_data.csv` — Acquisition-level estimates, fit decisions, and calculation parameters exported from analysis of the matching 5 November `.exp` file.
- `20261106_3HAE_5HTB_unannealed_reacquired.exp` — Raw Dynamics export for the 6 November reacquired unannealed 3HAE/5HTB measurements, generated by the DLS instrument software.
- `20261106_3HAE_5HTB_unannealed_reacquired_plot_data.csv` — Acquisition-level estimates, fit decisions, and calculation parameters exported from analysis of the matching 6 November reacquired `.exp` file.
- `20261106_annealed_5HTB.exp` — Raw Dynamics export for the 6 November annealed 5HTB measurements, generated by the DLS instrument software.
- `20261106_annealed_5HTB_plot_data.csv` — Acquisition-level estimates, fit decisions, and calculation parameters exported from analysis of the matching 6 November `.exp` file.

### `DLS/plots/`

- `20261103_3HAE-annealed (2)/` — PDI and diameter-versus-PDI plots for the matching `.exp` file.
- `20261103_3HAE-annealed/` — PDI and diameter-versus-PDI plots for the matching `.exp` file.
- `20261103_3HAE-annealed_notsure5htb/` — PDI and diameter-versus-PDI plots for the matching `.exp` file.
- Additional analysis notebooks save individual plots in a subfolder named for their dataset or comparison.
- `dls_pdi_summary.csv` — Per-file and per-measurement acquisition counts, mean accepted-fit PDI, and median accepted-fit diameter, written by `analyze_dls.py` alongside the plots.
